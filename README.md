## Question 5: Describe refactoring and its benefits.

Refactoring is when a programmer goes back to code that is already written and makes changes to improve how the code is organized. The main idea is to make the code cleaner and easier to understand without changing what the program actually does. For example, if I have the same code repeated several times, I could put that code into a function instead of writing it again and again. I can also change confusing variable names, remove code that is not needed, or break a large part of a program into smaller sections.

Refactoring is helpful because code can become difficult to read as a program gets bigger. Having organized code makes it easier to find mistakes and understand what each part of the program is doing. It can also make it easier to add something new later without changing the entire program. As I am still learning programming, refactoring can help me look back at my code and find simpler ways to write it. The program may already work, but refactoring can make the code easier to read, maintain, and work with later.
